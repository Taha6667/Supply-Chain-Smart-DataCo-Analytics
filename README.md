# Supply Chain Smart DataCo Analytics (Capstone Project)

End-to-end Supply Chain data cleaning, referential-integrity validation, and executive BI reporting built during the **DigiLians (MCIT)** Professional Data Analysis program (Team Vertex Labs).

# Role & Key Contributions
*Data Quality Engineer & Validation Gate Lead**
*Data Cleaning & Auditing (`Validation Queries.sql`):** Cleaned and audited Customer, Logistics, and Reference datasets across **16 interrelated tables** using T-SQL.
*Star Schema & Referential Integrity:** Verified the Star Schema data model and validated **15 PK/FK relationships**to eliminate orphan records and ensure 100% data integrity before handoff to the BI reporting layer.
* **Database Views (`Views Tables.sql`):** Developed structured SQL views to support clean reporting queries.
* **BI Dashboard (`Supply Chain.pbix`):** Collaborated on interactive Power BI executive dashboards tracking supply chain performance, order delivery, and profitability KPIs.

#Tech Stack
* **Database & Querying:** SQL Server (SSMS), T-SQL
* **Data Modeling:** Star Schema, Referential Integrity Constraints
* **Business Intelligence:** Power BI, Power Query (ETL), DAX
